## 你将完成什么

这条路径把一个 API Key 模型渠道接入默认 App：保存 Provider、读取模型目录、选择模型、应用配置，然后启动一次真实对话。

## 开始前

- 安装并打开 R Codex 桌面应用。
- 准备一个 OpenAI 兼容模型渠道的 API Key 和 Base URL。
- 确认当前版本支持 macOS 发布链路；Windows 包仍在补齐。

## 四步完成配置

### 1. 添加模型渠道

打开“模型渠道”，填写名称、Base URL 和 API Key。API Key 只存进系统凭据库，页面只显示脱敏状态。

### 2. 执行检测

运行连通性检测。R Codex 会尝试读取 `/models`，并按渠道能力执行最小文本请求。检测失败时先看错误类型：认证、网络、协议和上游响应分别处理。

### 3. 加入工作区

在默认环境卡中加入渠道，勾选要提供给 Codex 的模型，确认公共模型 ID 和默认模型。不同渠道的同名模型会自动加上来源前缀，避免选错上游。

### 4. 应用并启动

点击“应用默认 App 模型配置”后重启默认 App；也可以点击“启动默认 App”，由 R Codex 带着回环代理排除变量打开它。

## 第一次请求失败怎么办

先打开“历史与测试记录”，确认 Gateway 是否收到请求。收到请求但返回 502，继续看上游状态和脱敏错误摘要；完全没有 Gateway 记录时，优先检查系统代理是否接管了 `127.0.0.1` 回环请求。

详细处理见 [Gateway 与 502](../guides/gateway-502/)。
