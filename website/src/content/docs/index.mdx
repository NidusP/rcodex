## 先把默认 App 用起来

首版优先支持默认 App：添加 API Key 模型渠道，检测可用模型，把路由应用到默认配置，再从 R Codex 启动或重启 App。默认 App 的认证、会话和历史仍归 Codex 自己管理。

## 从配置到对话

1. 在“模型渠道”中保存 API Key Provider，并执行连通性检测。
2. 在工作区选择检测到的模型，确认公共模型 ID 和默认模型。
3. 点击“应用默认 App 模型配置”，然后重启默认 App；或直接从 R Codex 启动默认 App。
4. 如果请求失败，从 Gateway 诊断中查看错误层级、上游状态和下一步动作。

## 先理解边界，再开始使用

R Codex 不修改默认 `auth.json`，不把第三方 API Key 注入 Codex 子进程，也不记录请求正文或响应正文。隔离 App、官方账户模型和三方模型旧会话兼容性仍在验收，官网会持续更新真实状态。
